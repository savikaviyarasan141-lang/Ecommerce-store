\# 🛒 E-Commerce Web Application



A full-stack e-commerce web application built using React, Flask, and MySQL.



\## 🚀 Features



\### 👤 User Features

\- User registration and login

\- Browse products

\- Add products to cart

\- Increase/decrease product quantity

\- Remove products from cart

\- Checkout

\- Add shipping address

\- View order history

\- View order details



\### 👨‍💼 Admin Features

\- Admin login

\- Add products

\- Edit products

\- Delete products

\- View all customer orders

\- Update order status

\- Manage product stock
